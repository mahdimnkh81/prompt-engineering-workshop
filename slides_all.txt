📝  Prompt Examples
---

---
❌  Without technique
---
Read the text below and give me a JSON of the employees and their departments.
---

---
✅  With technique
---

Extract the organizational data from the text. Respond with valid JSON ONLY. Use the exact relational schema below, using dept_id as a foreign key to link employees to their departments:{ 
"departments": [ { "dept_id": "d1", "name": "..." } ],
 "employees": [ { "emp_id": "e1", "name": "...", "department_id": "d1" } ] 
}
